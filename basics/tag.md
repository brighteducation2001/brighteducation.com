# Tag	Purpose:-
1) <b>	Makes text bold.

2) <strong>	Indicates important text (also bold by default).

3) <i>	Makes text italic.

4) <em>	Emphasizes text (usually italic).

5) <u>	Underlines text.

6) <mark>	Highlights text with a background color.

7) <small>	Displays smaller text.

8) <sub>	Creates subscript text (e.g., H₂O).

9) <sup>	Creates superscript text (e.g., x²).

10) <a>	Creates a clickable hyperlink.

11) <img>	Displays an image.

12) <ul>	Creates a bulleted (unordered) list.

13) <ol>	Creates a numbered (ordered) list.

14) <li>	Represents a list item.

15) <table>	Creates a table.

16) <tr>	Defines a table row.

17) <th>	Defines a table header cell.

18) <td>	Defines a table data cell.

19) <form>	Creates a form to collect user input.

20) <input>	Creates input fields like text, email, password, etc.

21) <label>	Adds a label for an input field.

22) <select>	Creates a dropdown list.

23) <option>	Represents an item inside a dropdown.

24) <textarea>	Creates a multi-line text input.

25) <button>	Creates a clickable button.

26) <footer>	Defines the footer section of a webpage.
